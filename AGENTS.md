# MAIN RULES
Make regular commits to your repository. This will help you track your progress and make it easier to revert changes if needed.
Follow a consistent coding style and naming conventions. This will make your code more readable and maintainable.
Write clear and concise commit messages that describe the changes you made. This will help you and others
More commits = more rewards. The more you contribute, the more you will be rewarded for your efforts.
